# Getting Help

Thanks for using The Learning Hub. Here is where to go for each kind of
question.

## Something in a guide is wrong

Open a guide error issue in that guide's repository. Include the section
heading and what you expected to see.

## You have a question about a topic

Check the guide's table of contents and its Stage 7 interview handbook first.
If the answer is not there, open an issue in the guide's repository and
describe what you tried. For questions that go beyond the guide, the tool's
own documentation and community forums are often the fastest route.

## You want a guide that does not exist yet

Open a new guide request issue. Check the
[organization profile](https://github.com/TheLearningHubOrg) first to see
whether the topic is already covered.

## You found a security problem

Do not open a public issue. Follow the
[Security Policy](https://github.com/TheLearningHubOrg/.github/blob/main/SECURITY.md).

## Response times

The guides are maintained by volunteers. Most issues get a reply within a
week, but there is no guaranteed response time.
